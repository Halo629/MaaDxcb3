## ✨ 主要功能

### 📅 日常任务

- 🤖 **管家任务** - 一键完成每日日常（女神像收益领取、农场生产产品、挑战盗宝贼费迪南德、奥术灰烬收益领取、通天塔每日收益领取、荒魂搜索、灵龛中的工坊、秘境洞穴、比比奇的坩埚、无尽的财富岛、马车商店购买、每日魂师指南、每周魂师指南、藏宝图领取）
- 🎁 **日常奖励领取** - 自动领取每日奖励（领取邮件、每日免费玉领取、月卡领取、公会挑战&商店购买、珍藏商店购买招魂师卷轴、基础月卡到期自动购买等）
